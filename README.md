DompetKeluarga is a working household budget site for an Indonesian family, with real rupiah figures: a month dashboard, transactions you can add, edit and delete, per-category budgets, bills and reminders, savings goals, and monthly reports with pure-canvas charts — all offline, all saved in your own browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, no account.
